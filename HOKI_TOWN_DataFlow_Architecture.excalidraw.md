# 🎨 HOKI TOWN — Client-Server Data Flow Architecture

ผังแสดงวงจรการรับส่งข้อมูลระหว่าง **Client Controller**, **RemoteEvents (Networking)**, **Server Backend**, **Workspace DataModel** และ **ProfileStore Persistence**

## 🧩 Text Elements Summary
- **📱 CLIENT LAYER (StarterPlayer):** CDT Arcade Drive, ContextActionService Sink, Tap-to-Drift, 60 FPS Gauge Rendering, Raycast Smoke Snap.
- **📡 NETWORK LAYER (ReplicatedStorage.Remotes):** `VehicleRepairRequest`, `VehicleImpactEvent`, `HarvestCropRequest`, `FetchPlayerData`.
- **🖥️ SERVER BACKEND (ServerScriptService):** VehicleService Authority, Anti-Cheat Guard, Centralized Collision Listener, Fuel/Damage Loop, Farming Validator.
- **🌍 WORKSPACE DATAMODEL:** TeslaRoadster Physics, 10 Explosive Barrels, Kinematic Totems, 1,552 Road Segments.
- **💾 PROFILESTORE:** Cash/Bank, Owned Vehicles, Inventory Stash, Session Locking.
